# Contributing to Quicklyzer

Thank you for your interest in contributing.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/sabtain05/quicklyzer.git
```

Install dependencies:

```bash
npm install
```

Run development mode:

```bash
npm run dev
```

---

## Pull Requests

Please ensure:

- Code builds successfully
- Tests pass
- New features include documentation
- Keep pull requests focused

---

## Coding Style

- TypeScript
- ES Modules
- Clear naming
- Small reusable functions

---

## Reporting Issues

Please include:

- Operating System
- Node.js version
- Quicklyzer version
- Steps to reproduce
- Expected behavior
- Actual behavior

---

Thank you for helping improve Quicklyzer.
