# Code of Conduct

## Our Pledge

We are committed to making participation in this project welcoming and respectful for everyone.

---

## Expected Behavior

- Be respectful.
- Be constructive.
- Accept feedback.
- Help others learn.
- Communicate professionally.

---

## Unacceptable Behavior

- Harassment
- Personal attacks
- Discrimination
- Trolling
- Spam
- Publishing private information

---

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct and may remove comments, issues, or pull requests that violate these guidelines.

---
