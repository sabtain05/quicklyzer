# Security Policy

## Supported Versions

| Version | Supported |
|----------|-----------|
| 1.x | ✅ |
| 0.x | ❌ |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please do not create a public issue.

Instead:

1. Describe the vulnerability.
2. Include reproduction steps.
3. Explain the potential impact.
4. Include the Quicklyzer version.

The maintainer will investigate and respond as quickly as possible.

---

## Security Best Practices

- Always use the latest version of Quicklyzer.
- Keep Node.js updated.
- Review third-party dependencies regularly.
- Report vulnerabilities responsibly.

Thank you for helping keep Quicklyzer secure.
