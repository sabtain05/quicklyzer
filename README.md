## Installation

### Using npm

```bash
npm install -g quicklyzer
```

### Using npx

```bash
npx quicklyzer scan
```

---

# Commands

## Analyze Project

```bash
quicklyzer scan
```

## About

```bash
quicklyzer about
```

## Version

```bash
quicklyzer version
```

## Export Report

```bash
quicklyzer export
```
