# Installation

```bash
npm install -g quicklyzer
```

or

```bash
npx quicklyzer scan
```

---

# Usage

Analyze the current project:

```bash
quicklyzer scan
```

Show version:

```bash
quicklyzer version
```

About Quicklyzer:

```bash
quicklyzer about
```

Export report:

```bash
quicklyzer export
```
